# 🔐 Password Strength Analyzer

A simple Python-based **Password Strength Analyzer** that evaluates the strength of a user-entered password based on length, character complexity, and repeated characters.

The project is designed to demonstrate basic **password security concepts** and help users understand how to create stronger passwords.

---

## 📌 Features

- ✅ Checks password length
- ✅ Checks for lowercase letters
- ✅ Checks for uppercase letters
- ✅ Checks for numbers
- ✅ Checks for special characters
- ✅ Detects repeated characters
- ✅ Provides password strength levels
- ✅ Gives suggestions to improve weak passwords
- ✅ Simple command-line interface
- ✅ No external libraries required

---

## 🛠️ Technologies Used

- **Python 3**
- `string` module
